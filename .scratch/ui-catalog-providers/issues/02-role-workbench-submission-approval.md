**What to build:** 将任务 01 选定的 A「侧栏工作台」重写为正式 Next.js UI，连接现有会话、目录和 Job HTTP Interface，让 owner 与 collaborator 可以完成角色化首页、评测列表、三步提交、详情、批准/拒绝、取消和中断恢复/新建重试。

**Spec stories:** 1–15，以及 24–27 中任务 02 仅需保留的既有结果入口。

- [x] A 版侧栏壳提供角色化首页、URL 可恢复导航和 390/360 手机菜单；登出清掉私有页面状态。

- [x] 产品 UI 不展示任何缺少现存后端 API 的业务按钮或业务交互，不用前端假数据、假成功或占位动作暗示未完成能力已经完成。
