# 03：先看对比，再看单次证据

- Published: 2026-09-21
- Baseline: `fd369cc`
- Action: `docs/actions/2026-09-21-ui-comparison-report.md`

## 前置

- 02 的会话/导航壳和用户确认的报告原型。
- 既有批次、Run 报告、制品/轨迹、排行榜、保留清理合同。
- 既有 `GET /api/v1/reports/comparisons`、Job 详情和 Run 报告接口。

## 范围

1. 复用批次报告构建题目 × 配置矩阵；分别汇总确定性通过、未通过、基础设施故障、未完成和缺失。
2. 缺失 Run 或报告只标为缺失，不当作未通过或零。
3. Run 用量和资源按需、有限并发加载；只有组成值全部可用时称“总量”，否则标为部分或未知。
4. 展示冻结模型、版本、限制、工具与网络策略差异；不以 UI 排序替代后端排行榜，也不引入 Judge 分。
5. 单元格进入既有单次报告与证据，保留确定性判卷、安全日志/补丁/轨迹、下载和过期提示。
6. 错误码附通俗说明、技术字段折叠；费用仅沿用可靠美元合同，不把人民币预算当账单。
7. 题库、配置、owner 成员/保留管理维持独立导航；协作者仍可查看获准的非秘密目录；不增加 Key 页面。

## 非目标

- 不新增后端接口、数据库结构、Judge 评分、估算价格或补写模型轨迹。
- 不进入尚未获用户确认的题库阶段。
- 不借测试写入共享业务数据库。

## 验收

- [x] 混合成功/未通过/基础设施故障/取消或未完成/缺失报告的矩阵和汇总正确。
- [x] 缺失和未知不被算作失败或数值 0。
- [x] 零用量与未知明确不同；Run 用时注明是各 Run 汇总而非整批墙钟。
- [x] 用量加载为用户触发且存在并发上限。
- [x] 页面权限不变，隐藏资源仍由服务端拒绝。
- [x] 桌面和手机均可从矩阵钻取单次详情、查看轨迹、下载制品并处理既有管理操作。
- [x] 既有 UI 动线无功能丢失；不出现没有后端合同的按钮或交互。
- [x] Web 与后端全量回归完成，真实失败和环境限制如实记录。

## 停止条件

- 某项指标没有可靠来源时显示未知，不估造价格、准确率或轨迹。
- 03 验收完成后等待用户确认 UI，再安排题库阶段。
