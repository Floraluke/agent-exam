# 01：可点击 HTML 原型与选定设计

**What to build:** 使用明显标注的合成数据制作一个离线、可点击、可在三种浅色布局间切换的 Web 工作台原型，帮助用户在修改产品代码前确认信息结构和交互方向。

**Blocked by:** 无；只读既有产品事实，不连接真实服务。

**Spec stories:** 1–15、24–27 中的界面呈现部分。

- [x] 提供侧栏工作台、紧凑任务收件箱、分区概览三种结构明显不同的布局，并通过 `?variant=A|B|C` 与可见切换器比较。
- [x] owner 与协作者都有角色化首页；两者共用 Job 详情、批次报告与单 Run 证据入口。
- [x] 新建评测使用“选题→选配置→核对提交”三步向导，前后切换不丢失选择，并明确提交后等待 owner 批准。
- [x] owner 可以在原型中查看冻结摘要并模拟批准、拒绝、取消、恢复/新建重试；协作者看不到管理动作。
- [x] 批次报告展示“题目×配置”矩阵，可区分已解决、未解决、基础设施故障、未完成和缺失，并可钻取单 Run 详情。
- [x] 场景切换覆盖空列表、待批准、排队、执行、完成、未通过、基础设施故障、取消、无权限、会话过期、断网、制品过期、轨迹/用量缺失。
- [x] 桌面覆盖 1440/1280，手机覆盖 390/360；手机主导航和主操作不截断，矩阵仅在带标题区域内横向滚动。
- [x] 键盘焦点、表单提示和布局切换可理解；所有按钮均为内存演示，不产生真实网络写入，不包含秘密。
- [x] 用户查看三种方案并明确选择纯 A「侧栏工作台」；B/C 不混入产品基线。任务 02 仍须另行安排，并先完成逐控件前后端契约映射。
