# 03: 任务与 Codex 配置目录

**What to build:** 登录用户可在页面浏览固定版本的 SWE-Gym 任务及已登记 Codex 配置，了解将评测什么；所有者通过受控入口维护目录，历史身份与原始任务快照可追溯。

**Blocked by:** 01 所有者登录与本机恢复

**Status:** ready-for-agent

**Spec stories:** 6, 7, 8, 9, 10, 11, 51

- [ ] 任务列表、筛选和详情页面通过 HTTP 获取真实目录数据；展示固定任务身份与问题描述，空列表、无效筛选、缺失任务和依赖失败有明确反馈。
- [ ] 受控登记同时保存标准任务字段与内容哈希固定的原始快照；重复登记不悄悄改写同一身份的内容，失败不产生可用的半登记任务。
- [ ] 普通页面、接口响应与被测 Agent 的任务渲染均不能获得参考补丁、隐藏测试或判分答案；沿用已有任务适配与可见性边界。
- [ ] 配置目录展示 Agent 版本、提供方、模型及公开关键配置，保留完整配置指纹；秘密、宿主路径、启动命令和模型地址不能进入公开配置。
- [ ] 只有所有者可登记或禁用固定 Codex 配置；禁用不删除历史身份，不允许用户提交任意启动脚本或代理覆盖。
- [ ] 任务与配置元数据使用 PostgreSQL，原始快照使用不可变 MinIO 制品；真实集成验证哈希关联、重复登记以及数据库/对象存储单侧失败。
- [ ] HTTP 覆盖目录查询、登记权限和隐藏字段拒绝，浏览器覆盖任务与配置浏览；任务 02 接通后补充实际协作者会话回归，不把此交叉回归误写成任务 03 的前置依赖。
- [ ] 新建独立行动记录并同步架构/接口/数据和依赖信息；固定版本以已查证值为准，新增边界按项目规则确认，验证后本地提交、不推送。
