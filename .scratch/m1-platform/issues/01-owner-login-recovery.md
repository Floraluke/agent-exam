# 01: 所有者登录与本机恢复

**What to build:** 评测机所有者可在本机建立唯一账号，在页面登录、查看当前身份并退出；遗失访问能力时，通过本机受控恢复重新登录。账号实际持久化，不以网页假登录代替。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Spec stories:** 1, 3, 4, 51

- [x] 实施前完成身份职责承载检查；新增 Module、Interface、表和目录的最小方案已获用户确认，并同步架构、数据及 HTTP 契约，不将候选设计写成既成事实。
- [x] 本机引导可建立唯一 owner，重复或并发引导不能产生第二个 owner；不提供公共注册、远程创建 owner 或远程恢复入口。
- [x] 登录页通过真实 HTTP 用例建立可信会话，显示当前应用身份并可退出；错误凭证、未登录、失效会话及依赖不可用有可观察的正确响应和页面提示。
- [x] 请求中的用户或角色字段不能提权；网络设备身份与 Codex 凭据都不能替代应用身份。
- [x] 密码不明文存储，会话秘密不进入日志或响应正文；会话过期、退出撤销和跨站请求防护在接口与浏览器边界验证。
- [x] 本机恢复保留同一 owner 身份和历史关联，使旧登录凭证及旧会话失效；恢复失败不留下半更新状态，不在命令行参数或输出中暴露密码。
- [x] PostgreSQL 保存账号与会话；验证进程重启后身份仍可用、唯一所有者约束和恢复事务回滚，内存替身不计为数据库集成通过。
- [x] 以 HTTP 与本机维护入口覆盖成功/拒绝/恢复路径，少量浏览器测试覆盖登录、身份显示和退出；不创建用户真实账号、不触碰现有服务数据，实际集成环境使用前核对范围。
- [x] 新建本任务的独立行动记录，记录红绿测试、静态检查、集成结果与未验证项；关键节点只做范围清晰的本地提交，不推送。
