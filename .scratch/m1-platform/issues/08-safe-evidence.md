# 08: 安全证据与轨迹查看

**What to build:** 有权限的用户从逐题报告查看补丁、测试摘要和分页可观察轨迹，按允许范围读取或下载证据；秘密、隐藏答案和不应公开的原始内容始终留在受限边界内。

**Blocked by:** 06 单题执行与最小报告

**Status:** ready-for-agent

**Spec stories:** 5, 8, 36, 37, 38, 39, 40, 41, 51

- [ ] 页面、HTTP 查询和下载采用一致的应用身份与资源授权；不能仅靠猜测对象键、Run 标识或前端隐藏绕过限制。
- [ ] 报告关联最终补丁、测试摘要与可发布证据，轨迹按契约分页且顺序稳定；只展示可观察事件和必要摘要，不索取或泄漏私密思维链。
- [ ] 公开响应、下载、错误、日志和可共享对象均保护凭据、宿主私有路径、参考补丁和隐藏测试；用合成秘密正反例验证，不能把检测到刻意泄漏称为防泄漏通过。
- [ ] 所有者本机私有原始输出的暂缓清洗例外不适用于页面、共享存储发布、下载或外部分析；无法证明可安全发布的正文拒绝提供并说明状态。
- [ ] 制品与所属 Run、种类、哈希、大小和内容类型对应；写入不可覆盖，读取发现错配、损坏、缺失或未就绪时明确失败，不返回假空文件或假完整报告。
- [ ] 补丁阈值提示与拒绝状态在页面可见；不得为便于展示而改变进入判卷的原始 patch 字节或掩盖截断。
- [ ] HTTP 覆盖授权、分页、完整性和错误响应；浏览器覆盖报告到轨迹/下载；真实 MinIO/PostgreSQL 集成覆盖不可覆盖、断流和单侧故障，测试内容仅含合成数据。
- [ ] 本任务独立行动记录保存输出保护的实际证据和未覆盖风险，同步接口/架构/认证相关事实；不调用 Judge，不发布私有原始证据，本地提交、不推送。
