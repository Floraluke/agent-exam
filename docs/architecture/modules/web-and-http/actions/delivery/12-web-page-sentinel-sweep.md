## 5. 未验证 / 局限

- 只扫**页面文本**（`body` 的可见文本），不扫 DOM 属性、网络响应、`localStorage` 或注释；这与 C 的 HTTP 面扫描是互补关系，不是替代。
- 哨兵是**固定清单**：新增一类敏感字段（例如未来某个新端点返回的新标识）不会自动被覆盖，需要有人往 `SENTINELS` 里加值。
- 排行榜的扫描只覆盖**有行**的状态；空状态（"没有符合条件的正式结果。"）不承载服务端字段，故未单独扫描。
