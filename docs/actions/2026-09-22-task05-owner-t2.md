## ② 固定 Harbor 侧车附加：结论、入口与停止条件

**结论：允许调用方按服务绕过默认侧车附加，但不等于允许无条件关闭内置侧车，也不等于 T2 已运行通过。** `network_mode` 是 `service:harbor-docker-egress-control-sidecar`，不是字面上的 `container:<主容器>`；效果是主服务使用侧车的网络命名空间。[`docker.py:410–449`](../../framework/harbor/src/harbor/environments/docker/docker.py) 读取任务 Compose 与 `extra_docker_compose_paths`，含 `networks`/`network_mode` 的服务被排除。关键源码：

```python
# framework/harbor/src/harbor/environments/docker/docker.py:433-449, 466-473
uses_explicit_networking = isinstance(config, dict) and (
    "network_mode" in config or "networks" in config
)
# ...
if not uses_explicit_networking and name != self._EGRESS_CONTROL_SERVICE_NAME
# ...
"network_mode": f"service:{self._EGRESS_CONTROL_SERVICE_NAME}",
"depends_on": {self._EGRESS_CONTROL_SERVICE_NAME: {"condition": sidecar_condition}},
```

配置入口：[`JobConfig.environment`](../../framework/harbor/src/harbor/models/job/config.py)、[`job_plan.py:158`](../../framework/harbor/src/harbor/job_plan.py) 将环境配置传给 Trial；[`Trial EnvironmentConfig.extra_docker_compose: list[Path]`（215 行）](../../framework/harbor/src/harbor/models/trial/config.py) 经[`factory.py:357`](../../framework/harbor/src/harbor/environments/factory.py)送入 DockerEnvironment，再由[`docker.py:392–405`](../../framework/harbor/src/harbor/environments/docker/docker.py)排在生成的侧车覆盖文件之前。环境目录的 `docker-compose.yaml` 也被读取。最小**静态候选**是在额外 Compose 文件中给 `services.main` 声明显式 `networks`，并定义对应网络：

```yaml
services:
  main:
    networks: [internal]
networks:
  internal:
    internal: true
```

调用方须把该文件路径填入 Run/Trial 的 `environment.extra_docker_compose`，或在任务环境目录提供 `docker-compose.yaml`；真实双网络还需受控 proxy 与 fake-upstream 服务及 egress 网络、标签等完整定义。仅靠这段 YAML **不能**宣称防绕过或 T2 成功。现有[`compose_profile()`（63–64 行）](../../apps/backend/src/eval_platform/adapters/execution/network.py)刻意不声明网络，会被上述覆盖文件附加；[认证接口 §4.1 第 5 条](../interfaces/CODEX_AUTHENTICATION.md)因此警告不能照搬。

**实际运行停止条件**：[`docker.py:204–215`](../../framework/harbor/src/harbor/environments/docker/docker.py)在非公网策略的 DockerEnvironment 构造期调用 `_egress_control_kernel_support()`；[`docker.py:918–950`](../../framework/harbor/src/harbor/environments/docker/docker.py)随后执行如下命令，容器没有允许范围要求的名称与标签：

```python
*cls._engine_cmd("container", "run", "--rm", cls._EGRESS_CONTROL_KERNEL_PROBE_IMAGE,
                 "sh", "-c", cls._EGRESS_CONTROL_KERNEL_PROBE_SCRIPT)
```

且[`docker.py:1104–1108`](../../framework/harbor/src/harbor/environments/docker/docker.py)默认删除路径可能执行 `down --rmi local --volumes --remove-orphans`，超出“不删镜像、只按名称与标签删除”的授权。不修改固定 Harbor、不将网络策略放宽为公网、不跳过它的内核检查，因此本轮没有启动 Harbor 实证，也没有暗称侧车已经安全替换。
